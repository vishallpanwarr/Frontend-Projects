# 🚀 Web Development Projects

A curated collection of beginner-friendly to intermediate web development projects built using pure **HTML**, **CSS**, and **JavaScript**. This repository showcases various creative animations, interactive games, UI components, and utility applications.

---

## 📂 Project Directory

### 🎬 Creative Animations & 3D CSS
* **3D Cube**: A rotating 3D cube built entirely with CSS transforms.
* **3D Earth**: A CSS-styled spinning model of the Earth.
* **Saturn Animation**: A visual representation of Saturn with animated rings.
* **DNA Animation**: A double-helix DNA strand animated using CSS.
* **Frog Animation**: A playful character animation utilizing keyframes.
* **Envelope Animation**: An interactive opening envelope effect.
* **Gmail Animation**: A CSS-based recreation of the Gmail logo/loading state.
* **Welcome Animation**: An eye-catching entrance or landing animation.
* **Text Animation**: Creative typography and text-reveal effects.
* **Tap Icon Animation**: Micro-interaction icons designed for user engagement.
* **Loading Animation**: A variety of sleek loaders and spinners.

### 🦾 Marvel & Pop-Culture Creations
* **Arc Reactor / Arc Reactor 2**: Tony Stark's iconic power source brought to life with CSS glow and rotation effects.
* **Iron Man Animation / Iron Man Animation 2**: Advanced CSS illustrations and animations themed around Iron Man.
* **Spiderman Animation**: A creative web-slinging or character-inspired visual project.

### 🎮 Games & Interactive Apps
* **Chess Game**: A playable chess interface built with web technologies.
* **Tic Tac Toe**: A classic, responsive two-player game.
* **Quiz App**: An interactive multiple-choice quiz application with score tracking.
* **Weather App**: A dynamic application fetching real-time weather data.
* **Random Password Generator**: A handy tool to generate secure, customizable passwords.
* **Movie List**: A searchable directory or watchlist application.

### 🖥️ UI Components & Web Pages
* **Tourism Website**: A multi-section layout highlighting travel destinations.
* **Cafe Menu Card**: A beautifully styled restaurant menu using modern CSS grid/flexbox.
* **Log In Page & Neon Animated Log In Page**: Clean and futuristic authentication screens.
* **Profile Card**: A sleek personal portfolio/social profile card.
* **Glass Morphism Card**: A modern UI design featuring frosted glass aesthetics (`backdrop-filter`).
* **Rubik's Cube**: An interactive CSS puzzle concept.

---

## 🛠️ Built With

* **HTML5**: For semantic page structure.
* **CSS3**: For styling, Flexbox, CSS Grid, 3D transforms, and complex keyframe animations.
* **JavaScript (ES6+)**: For DOM manipulation, game logic, and app interactivity (in apps and games).
